# Самооценка против kycnot.me + план роста trust

> **Правило этого документа: только проверяемые факты.** Каждый ✅ обязан подтверждаться кодом
> или живым сервисом. Завышать здесь — худшее, что можно сделать: kycnot.me проверяет заявления,
> и пойманный overclaim бьёт по trust сильнее, чем честно признанный пробел.
> Сверено с кодом 2026-07-16.

Формула рейтинга: **score = privacy × 0.6 + trust × 0.4**. У топов privacy = 100% (гигиена: no-KYC,
Monero/BTC/LN, no-email, no-logs). Различает **TRUST** (у топов 56–85%). Мы новый игрок без
репутации → trust — наше узкое место, закладываем осознанно.

## A. PRIVACY (цель — 100%, «гигиена»)

| Атрибут | Статус | Реализация |
|---|---|---|
| No-KYC регистрация | ✅ | account-number ≥66 бит, без PII ([account_number.py](../control-plane/app/services/account_number.py)) |
| Анонимная оплата | 🟡 | BTC (on-chain) + LTC + USDT-TRC20 через BlockBee, **non-custodial** (адрес-на-заказ, форвард на наш payout). **Monero НЕ подключён, Lightning НЕ подключён** — см. оговорку ниже |
| No-email (опц.) | ✅ | email опционален, шифрован Fernet ([email_crypto.py](../control-plane/app/services/email_crypto.py)), удаляемый |
| No-logs (трафик/сессии/DNS) | ✅ | [no-logs-inventory.md](no-logs-inventory.md); резолвер по-нодно без логов; журнал ноды в RAM (`Storage=volatile`); Caddy стрипает client-IP |
| Приватник не у сервера | ✅ | браузерный X25519 ([wg-keys.js](../web/static/wg-keys.js)), валидирован RFC 7748 в CI |
| Платёж не линкуется к аккаунту | ✅ | скраб invoice↔account после активации (обнуляется и on-chain-фингерпринт) |
| .onion-доступ | ✅ | server-rendered без обязательного JS + Tor HS ([infra/tor](../infra/tor)) |
| ⚠️ USDT-TRC20 | ⚠️ | прозрачная сеть + Tether-freeze; на `/buy` честно маркирован как менее приватный |

**Вывод по privacy: НЕ на уровне топов — и главная причина одна.** Все три доступные монеты
(BTC/LTC/USDT) — **прозрачные блокчейны**. Monero, который у топов kycnot.me является приватным
дефолтом, у нас **отсутствует**: `PaymentMethod.MONERO` есть в enum, но в `_METHODS` его нет,
payout-адрес XMR не задан, свой `monero-wallet-rpc` не поднят. Lightning тоже отсутствует
(BlockBee форвардит on-chain, отдельной LN-выплаты нет).

Это **осознанная позиция оператора на текущий момент**, а не забытая задача: приём денег работает
на трёх монетах, XMR отложен. Но для честного счёта: **пока нет XMR, privacy-профиль оплаты
объективно ниже топов**, и заявлять обратное нельзя. Остальные privacy-рычаги (no-KYC, браузерный
keygen, no-logs, .onion, скраб платежа) закрыты на уровне топов.

## B. TRUST (наше узкое место — растим осознанно)

| Атрибут | Сейчас (проверено) | План роста |
|---|---|---|
| Open-source | 🟡 код open-source-ready (секретов в репо нет), но **не опубликован** | Публикация под анон-репо — **wg-keys.js в первую очередь** (иначе «браузерный keygen» непроверяем) + reproducible builds |
| Чёткая юрисдикция + владелец | ❌ **оператор анонимен намеренно** | Осознанный размен: юрисдикцию и владельца публично не называем (это прямо сказано на [/faq](../web/templates/faq.html)), инкорпорации нет. Trust-балл теряем сознательно, компенсируем open-source + аудитом |
| Warrant canary | ❌ **осознанно не ведём** | НЕ в планах. Позиция Mullvad/Njalla/AirVPN: 14-дневная канарейка — footgun. [/transparency](../web/templates/transparency.html) объясняет честно; не «чинить» добавлением канарейки |
| Transparency report | 🟡 страница есть, отчёта по расписанию нет | Сообщаем по факту, а не по расписанию (так и написано на /transparency) |
| Внешний аудит | ❌ не проведён | Аудит кабинета+нод независимой фирмой → отчёт. **На сайте не упоминается вообще** (2026-07-22): раздел «пока не проведён» и ссылки на него сняты — в формуле kycnot.me слагаемого за аудит нет, а собственный дисклоуз в навигации каждой страницы работал рекламой пробела. Молчание ≠ оверклейм; спросят — отвечаем «нет», и это не станет ложью ни на одной странице |
| Ноды: no-swap + журнал в RAM | ✅ | `swapoff -a` с abort'ом если swap выжил, `journald Storage=volatile`, unbound `log-queries: no`. **Клиентских данных на диске нет** ([store.py](../node-agent/agent/store.py): пиры приходят через reattach) |
| Ноды: FDE / diskless | ❌ **FDE НЕТ**, диск не пустой | На диске ноды: `wg-private.key`, `identity.json`, `node-config.json`, `cp-cert.pin`, `agent.env` — это идентичность САМОЙ ноды, не данные юзеров. Заявлять «diskless/FDE» нельзя. План: LUKS на нодах + verifiable-build образа |
| Возраст/репутация | ❌ новый (продажи открыты 2026-07-16, клиентов ~0) | Время + аптайм-история + отзывы сообщества |
| Bug bounty / security.txt | ❌ | security.txt + PGP + bounty-программа |
| Локации | 🟡 две (NL, RO), обе в ЕС | 3-я вне ЕС (напр. Исландия) = юрисдикционная диверсификация |

**Trust сейчас (честная оценка):** низкий. Новизна не лечится кодом; плюс мы **сознательно
отказались** от трёх классических trust-артефактов (named owner, канарейка, названная юрисдикция)
в пользу opsec оператора. Это осознанный размен, а не недоделка — но в баллах kycnot.me он стоит
дорого, и притворяться, что артефакты есть, — прямой путь потерять и остаток доверия.

## C. Приоритеты роста trust (порядок)
1. **Опубликовать репо** (всё уже open-source-ready) + reproducible builds — самый дешёвый и
   самый весомый шаг: делает проверяемым главное privacy-заявление (браузерный keygen).
2. **Monero** — если решим вернуться: единственный способ поднять privacy-профиль оплаты до топов.
3. **Внешний аудит** кабинета и нод; публикация отчёта.
4. **security.txt + bug bounty**; публичный PGP.
5. **FDE на нодах** + verifiable-build образа — тогда «RAM-only/diskless» станет правдой.
6. **Аптайм/статус-страница** по локациям (из агрегатных health-метрик, без пер-юзер данных).

## D. Чего НЕ делаем ради score (анти-паттерны)
- Не вводим customer-KYC ни под каким предлогом.
- Не подключаем кастодиальный платёжный шлюз как основной (видит потоки, KYC оператора).
- Не логируем «чуть-чуть для abuse» — это сломало бы privacy-ядро; abuse только на уровне exit-IP.
- **Не заявляем несуществующее.** Канарейку, аудит, named owner, XMR, FDE — только по факту.
  Пойманный overclaim стоит дороже честного ❌.
