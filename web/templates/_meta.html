Every URL here comes from `canonical_url` / `og_image`, which the server builds from a WHITELIST of public hosts (app/seo.py), never from the raw Host header — an echoed Host would let a stranger declare their own URL canonical for our pages. The same mechanism keeps the .onion version self-referential, so og:image stays same-origin there and the "zero external resources" invariant survives. `meta_title` is handed in by the includer (base.html re-renders its own block via `self.title()`; landing.html is standalone and states it directly). It cannot be read here: `{% include %}` gives the included template its OWN block namespace, so `self.title()` inside this file would look for a `title` block that does not exist.
