# support-bot — приватный Telegram-релей для поддержки

Двусторонний саппорт без светки твоего личного аккаунта и без сторонних релеев.

**Поток:** юзер пишет боту → сообщение копируется тебе (оператору) в Telegram →
ты отвечаешь **реплаем** на скопированное сообщение → бот шлёт ответ юзеру.

## Приватность
- **Свой бот** (не @livegrambot и т.п.) → переписку не видит третья сторона.
- **long-polling** → нет входящих портов/вебхука, работает за фаерволом.
- юзер = только его Telegram `chat_id` (с VPN-аккаунтом НЕ связан — бот его не знает).
- на диск — только маппинг `{op_msg_id → user_chat_id}` для маршрутизации ответов;
  **содержимое переписки не логируется** (и в stdout без текста).
- `copyMessage` (не forward) → у тебя нет «переслано от», работает для текста и медиа.

## Настройка (оператор)
1. Создай бота у **@BotFather** → `/newbot` → имя + username (напр. `privacyvpn_support_bot`) → получи **токен**.
2. (опц.) `/setprivacy` → **Disable** — чтобы в будущем бот видел сообщения в группах (для 1:1 не обязательно).
3. Впиши в прод `/opt/privacyvpn/.env`:
   ```
   SUPPORT_BOT_TOKEN=<токен от BotFather>
   SUPPORT_BOT_OPERATOR_CHAT_ID=123456789   # твой личный chat_id (тот же, что для алертов)
   ```
4. `docker compose up -d --build support-bot`
5. Открой `t.me/<username_бота>` → `/start` с другого аккаунта → напиши тест → тебе прилетит → ответь реплаем → должно вернуться отправителю.

Без заданного `SUPPORT_BOT_TOKEN` контейнер **простаивает** (idle, не крэш-луп) — безопасно для деплоя до настройки.

## Ссылка на сайте
`t.me/<username_бота>` вписывается в `CP_SUPPORT_TELEGRAM_BOT` (прод `.env`) → появляется карточка «Поддержка в Telegram» на `/support`.
